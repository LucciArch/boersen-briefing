# Börsen-Briefing

Installierbare Web-App (PWA) mit einem täglichen Börsen-Briefing zum eigenen Depot.
Die Datei `data/briefing.json` wird jeden Morgen automatisch aktualisiert.

Keine Anlageberatung.

## Sprachkalender (`kalender/`)

Eigene Web-App: Termine per Sprache eintragen („Nächste Woche Dienstag um 10 Zahnarzt bei Dr. Weber“),
Erinnerung per Benachrichtigung und Übergabe an den Handy-Kalender. Aufruf: `<Pages-Adresse>/kalender/`.
